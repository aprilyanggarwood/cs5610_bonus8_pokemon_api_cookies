# Pokemon API

A small RESTful API for managing a Pokemon collection, built with
[Hono](https://hono.dev/) and MongoDB. Created for CS5610 (Bonus Assignment 7).

**Author:** April Yang

## What it does

Stores Pokemon in a MongoDB collection and exposes five REST endpoints to list,
read, create, update, and delete them. Data is validated as it arrives, and the
API returns appropriate HTTP status codes.

A Pokemon has: `_id` (assigned by MongoDB), `name`, `species`, `health`,
`level`, and `owner`.

## Requirements

- Node.js 22.17+
- A MongoDB connection string (e.g. a free MongoDB Atlas cluster)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file in the project root with your MongoDB connection string: MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>.mongodb.net/pokemon
   `.env` is gitignored and must never be committed.
3. Run the server:
   ```bash
   npm run dev
   ```
   It starts on http://localhost:3000 (the `dev` script watches for changes and
   loads `.env`).

## Endpoints

Base path: `/api/pokemon`

| Method | Path | Description | Success |
|---|---|---|---|
| GET | `/api/pokemon` | List all Pokemon. Optional `?owner=Name` filters by owner. | 200 |
| GET | `/api/pokemon/:id` | Get one Pokemon by id. | 200 |
| POST | `/api/pokemon` | Create a Pokemon. | 201 |
| PATCH | `/api/pokemon/:id` | Update the provided fields of a Pokemon. | 200 |
| DELETE | `/api/pokemon/:id` | Delete a Pokemon. | 204 |

### Notes on create (POST)

- `species` and `owner` are required.
- `name` defaults to `species` if not provided.
- `id`, `health`, and `level` are generated by the server; do not send an `id`.

### Validation and errors

- `400 Bad Request` — missing/invalid fields (e.g. empty `species` or `owner`,
  non-numeric `health`/`level`, or an `id` sent on create).
- `404 Not Found` — no Pokemon with that id (also returned for malformed ids).

## Example requests (curl)

```bash
# List all
curl http://localhost:3000/api/pokemon

# List by owner
curl "http://localhost:3000/api/pokemon?owner=April"

# Create
curl -X POST http://localhost:3000/api/pokemon \
  -H "Content-Type: application/json" \
  -d '{"species":"Pikachu","owner":"April"}'

# Get one (use a real id from the list)
curl http://localhost:3000/api/pokemon/<id>

# Update
curl -X PATCH http://localhost:3000/api/pokemon/<id> \
  -H "Content-Type: application/json" \
  -d '{"level":10}'

# Delete
curl -X DELETE http://localhost:3000/api/pokemon/<id>
```
